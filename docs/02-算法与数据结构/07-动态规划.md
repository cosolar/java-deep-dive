# 动态规划：四步法、五类模型与状态设计

> 定位：动态规划不是「套公式」，而是「用状态描述决策历史」。这一篇只讲四步法：定义状态、写转移、定初始化、定顺序；然后用五类模型（线性、背包、区间、序列、状态机）把这套方法练熟。目标是面试能推、工程能识别「这题其实是 DP」。

## 一、什么时候该想到 DP

三个信号：

1. **最优子结构**：大问题的最优解由子问题的最优解组成；
2. **重叠子问题**：递归会重复计算同一状态；
3. **无后效性**：状态确定后，后续决策只依赖当前状态，不依赖「怎么来的」。

如果子问题相互独立、不重叠，用分治；如果状态可以贪心选择，用贪心；如果都不满足，才考虑 DP。

## 二、四步法

### 2.1 定义状态

状态要能完整描述「到当前为止的决策结果」。常见定义：

| 定义 | 适用 |
|---|---|
| `dp[i]`：前 i 个元素的最优值 | 线性 DP、前缀型 |
| `dp[i]`：以 i 结尾的最优值 | LIS、子数组、子序列 |
| `dp[i][j]`：前 i 个、容量 j | 背包 |
| `dp[i][j]`：区间 [i, j] 的最优值 | 区间 DP、回文 |
| `dp[i][0/1]`：第 i 天持有/不持有 | 股票、状态机 |

状态定义错了，转移一定错。判断标准：**这个状态能不能推出下一步，且不遗漏情况**。

### 2.2 写转移

从「最后一步」倒推：最后一个元素选或不选、最后一个字符匹配或不匹配、最后一次操作是什么。

### 2.3 初始化与边界

- 空集：`dp[0]` 是什么；
- 容量 0：`dp[0][j]` 是什么；
- 越界：i-1、j-1 要保证合法；
- 不可能状态：用 `Integer.MIN_VALUE` / `INF` 标记，转移时跳过。

### 2.4 遍历顺序

- 一维线性：从左到右；
- 背包：物品外层，容量倒序（0-1）或正序（完全）；
- 区间 DP：按区间长度从小到大；
- 状态机：按时间从早到晚。

顺序错了，依赖没算出来，结果就是错的。

## 三、线性 DP：LIS 与最大子数组

### 3.1 最长递增子序列（O(n²)）

```java
int lis(int[] a) {
    int n = a.length, ans = 0;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
        }
        ans = Math.max(ans, dp[i]);
    }
    return ans;
}
```

`dp[i]` 是「以 i 结尾的最长递增子序列长度」；答案不是 `dp[n-1]`，而是所有 `dp[i]` 的最大值。

### 3.2 LIS 的 O(n log n) 解法

维护 `tails[l]`：长度为 `l+1` 的递增子序列的最小结尾。遍历每个数，用 `lowerBound` 找到第一个 ≥ 它的位置并替换；如果比所有 tails 都大，追加。

```java
int lisFast(int[] a) {
    int[] tails = new int[a.length];
    int len = 0;
    for (int x : a) {
        int l = 0, r = len;
        while (l < r) {
            int m = l + (r - l) / 2;
            if (tails[m] < x) l = m + 1;
            else r = m;
        }
        tails[l] = x;
        if (l == len) len++;
    }
    return len;
}
```

注意：`tails` 不是真正的 LIS，只是「每个长度的最小结尾」，用来算长度；要还原序列需要额外记录前驱。

### 3.3 最大子数组和

```java
int maxSubArray(int[] a) {
    int cur = a[0], ans = a[0];
    for (int i = 1; i < a.length; i++) {
        cur = Math.max(a[i], cur + a[i]);
        ans = Math.max(ans, cur);
    }
    return ans;
}
```

`cur` 是「以 i 结尾的最大和」；如果 `cur + a[i] < a[i]`，不如从当前重新开始。

## 四、背包：三类变体

### 4.1 0-1 背包

```java
// dp[j] = 容量 j 的最大价值；物品外层，容量倒序保证只用一次
for (int i = 0; i < n; i++) {
    for (int j = cap; j >= w[i]; j--) {
        dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

倒序的原因：`dp[j - w[i]]` 必须是「上一轮物品」的状态；正序会让当前物品被重复使用。

### 4.2 完全背包

容量正序：

```java
for (int i = 0; i < n; i++) {
    for (int j = w[i]; j <= cap; j++) {
        dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

正序允许同一物品被多次选入。

### 4.3 多重背包

每个物品有数量限制。两种写法：

- 加一维数量：`dp[i][j][k]`，复杂度高；
- 二进制拆分：把 `count` 个物品拆成 `1,2,4,...` 的组合，转成 0-1 背包，复杂度 O(cap × Σlog count)。

### 4.4 背包的常见变体

| 变体 | 变化 |
|---|---|
| 恰好装满 | 初始化 `dp[0]=0`，其余 `-INF` |
| 求方案数 | `dp[j] += dp[j-w[i]]` |
| 求最小价值 | `min` 代替 `max` |
| 二维费用 | 加一维容量，双重循环倒序 |
| 分组背包 | 每组只能选一个，组内遍历 |

## 五、编辑距离：二维字符串 DP

```java
int editDistance(String a, String b) {
    int m = a.length(), n = b.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (a.charAt(i - 1) == b.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + Math.min(dp[i - 1][j - 1],
                                Math.min(dp[i - 1][j], dp[i][j - 1]));
            }
        }
    }
    return dp[m][n];
}
```

`dp[i][j]`：`a` 前 i 个变到 `b` 前 j 个的最少操作；三种操作对应三个方向：

- 替换：`dp[i-1][j-1] + 1`；
- 删除：`dp[i-1][j] + 1`；
- 插入：`dp[i][j-1] + 1`。

用途：拼写纠错、DNA 比对、模糊匹配、diff 工具。

## 六、股票买卖：状态机 DP

### 6.1 一次交易

维护历史最低价：

```java
int maxProfit(int[] prices) {
    int min = Integer.MAX_VALUE, ans = 0;
    for (int p : prices) {
        min = Math.min(min, p);
        ans = Math.max(ans, p - min);
    }
    return ans;
}
```

### 6.2 无限次交易

所有上涨区间累加：

```java
int maxProfit2(int[] prices) {
    int ans = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) ans += prices[i] - prices[i - 1];
    }
    return ans;
}
```

### 6.3 最多 k 次交易

`dp[k][0/1]`：第 k 次交易、持有/不持有。滚动数组降维：

```java
int maxProfitK(int k, int[] p) {
    int n = p.length;
    int[] hold = new int[k + 1];
    int[] cash = new int[k + 1];
    Arrays.fill(hold, Integer.MIN_VALUE / 2);
    for (int price : p) {
        for (int t = 1; t <= k; t++) {
            hold[t] = Math.max(hold[t], cash[t - 1] - price);
            cash[t] = Math.max(cash[t], hold[t] + price);
        }
    }
    return cash[k];
}
```

状态机 DP 的关键是「持有/不持有」两个状态，以及交易次数维度。

## 七、区间 DP：回文与合并

### 7.1 最长回文子序列

```java
int lps(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = n - 1; i >= 0; i--) {
        dp[i][i] = 1;
        for (int j = i + 1; j < n; j++) {
            if (s.charAt(i) == s.charAt(j)) {
                dp[i][j] = dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[0][n - 1];
}
```

区间 DP 的遍历顺序：`i` 从后往前，`j` 从 `i+1` 往后，保证 `dp[i+1][j-1]` 先算。

### 7.2 矩阵链乘/合并石子

`dp[i][j]` 表示区间 `[i,j]` 的最优值，枚举分割点 k：

```text
dp[i][j] = min(dp[i][k] + dp[k+1][j] + cost(i,j))
```

按区间长度从小到大遍历，避免依赖未计算的状态。

## 八、状态压缩：把集合放进整数

当状态是「哪些元素被选过」，且 n ≤ 20 左右，可以用一个整数的二进制位表示集合：

```java
for (int mask = 0; mask < (1 << n); mask++) {
    for (int i = 0; i < n; i++) {
        if ((mask & (1 << i)) == 0) {
            int next = mask | (1 << i);
            dp[next] = Math.min(dp[next], dp[mask] + cost[mask][i]);
        }
    }
}
```

典型：旅行商问题（TSP）、状压 DP、集合覆盖。n 超过 25 时，2ⁿ 已经不可接受。

## 九、记忆化 vs 递推

| 方式 | 优点 | 缺点 |
|---|---|---|
| 记忆化（自顶向下） | 只算需要的状态，代码贴近递归思路 | 递归栈、哈希开销 |
| 递推（自底向上） | 无栈、常数小、可滚动数组 | 需要先想清顺序 |

面试建议：先用记忆化写对，再改递推；工程里状态多、依赖稀疏时记忆化更合适。

## 十、DP 的常见错误

1. **状态定义不完整**：漏了「是否持有」「是否用过」「从哪来」；
2. **初始化错**：求最大值时全填 0，导致不可能状态被当成合法；
3. **遍历顺序错**：背包正序/倒序混用、区间 DP 没按长度；
4. **边界越界**：`dp[i-1]` 在 i=0 时访问；
5. **答案取错**：LIS 取 `dp[n-1]` 而不是全局最大；
6. **空间优化后依赖错**：一维数组滚动时，倒序/正序没对应上。

## 十一、数位 DP：按位枚举

数位 DP 解决「在 `[0, N]` 中，满足某条件的数有多少个」，例如「不含 4」「数位和不超过 k」「相邻位差 ≤ 2」。

### 11.1 状态设计

- `pos`：当前处理到第几位；
- `tight`：是否受 N 的上界限制；
- `started`：是否已经开始（处理前导零）；
- `state`：题目需要的额外状态（上一位、数位和、是否出现某模式）。

### 11.2 模板

```java
int countWithout4(int n) {
    char[] digits = String.valueOf(n).toCharArray();
    int[][][] memo = new int[digits.length][2][2];
    for (int[][] a : memo)
        for (int[] b : a) Arrays.fill(b, -1);
    return dfs(0, 1, 0, digits, memo);
}

int dfs(int pos, int tight, int started, char[] d, int[][][] memo) {
    if (pos == d.length) return started == 1 ? 1 : 1; // 0 也算
    if (memo[pos][tight][started] != -1) return memo[pos][tight][started];
    int limit = tight == 1 ? d[pos] - '0' : 9;
    int ans = 0;
    for (int x = 0; x <= limit; x++) {
        if (x == 4) continue;
        int ntight = (tight == 1 && x == limit) ? 1 : 0;
        int nstarted = started == 1 || x != 0 ? 1 : 0;
        ans += dfs(pos + 1, ntight, nstarted, d, memo);
    }
    return memo[pos][tight][started] = ans;
}
```

注意：

- `tight` 只在「当前位等于上限」时继续受限于下一位；
- 前导零是否算「出现过某数字」要按题意；
- 记忆化只对 `tight=0` 的状态复用，`tight=1` 不能缓存（或单独处理）。

### 11.3 数位 DP 的工程映射

- 号码/编号合规校验；
- 批量生成满足规则的 ID；
- 统计区间内满足条件的数量。

## 十二、树形 DP：在树上做决策

树形 DP 的典型模式是「选/不选当前节点」，用后序遍历合并子树。

### 12.1 打家劫舍 III

```java
int[] dfs(TreeNode root) {
    if (root == null) return new int[]{0, 0};
    int[] l = dfs(root.left);
    int[] r = dfs(root.right);
    int rob = root.val + l[1] + r[1];          // 选当前，孩子不能选
    int skip = Math.max(l[0], l[1]) + Math.max(r[0], r[1]);
    return new int[]{rob, skip};
}
```

返回 `[选当前的最大值, 不选当前的最大值]`，答案取 `max`。

### 12.2 树形 DP 的常见维度

- 选/不选；
- 子树大小；
- 到根的路径状态；
- 是否包含某类节点。

树形 DP 的遍历顺序是后序：先算子节点，再合并到父节点。

## 十三、单调队列优化 DP

当转移方程形如：

```text
dp[i] = min/max(dp[j] + cost(i, j))，j ∈ [i-k, i-1]
```

如果 `cost` 可分离，且窗口固定，可以用单调队列把 O(nk) 降到 O(n)。

### 13.1 滑动窗口最大值

```java
int[] maxWindow(int[] a, int k) {
    int n = a.length;
    int[] res = new int[n - k + 1];
    Deque<Integer> q = new ArrayDeque<>(); // 存下标，值单调递减
    for (int i = 0; i < n; i++) {
        while (!q.isEmpty() && q.peekFirst() <= i - k) q.pollFirst();
        while (!q.isEmpty() && a[q.peekLast()] <= a[i]) q.pollLast();
        q.offerLast(i);
        if (i >= k - 1) res[i - k + 1] = a[q.peekFirst()];
    }
    return res;
}
```

### 13.2 DP 优化示例

```text
dp[i] = max(dp[j] + a[i] - a[j])，j ∈ [i-k, i-1]
      = a[i] + max(dp[j] - a[j])
```

把 `dp[j] - a[j]` 放进单调队列，每次取队首最大值，O(n)。

### 13.3 适用边界

- 窗口必须是滑动的（固定长度或单调扩张）；
- 代价函数要能拆成「只与 j 有关」的部分；
- 如果窗口不固定或代价不可分离，单调队列不适用。

## 十四、DP 调试清单

DP 写错时，按顺序检查：

1. **状态定义**：是否完整描述决策历史？是否遗漏「持有/用过/从哪来」？
2. **转移**：是否覆盖所有前驱？有没有漏「不选」的情况？
3. **初始化**：空集/0 容量/第一行第一列是否正确？不可能状态是否标记？
4. **遍历顺序**：依赖是否先算？背包正序/倒序是否对应？
5. **边界**：`dp[i-1]` 在 i=0 是否越界？
6. **答案**：取 `dp[n]`、`dp[n-1]` 还是全局最大？
7. **空间优化**：滚动数组是否覆盖了还要用的旧值？
8. **手算验证**：n=1、n=2、全相同、全不同，和暴力解对比。

最有效的调试方法是**写一个暴力递归**，用小数据对拍；不要盯着转移方程猜。

## 面试高频问法

**Q1：动态规划怎么定义状态？**

一句话结论：状态要能完整描述「到当前为止的决策结果」，且满足无后效性；先写转移，再定遍历顺序。

展开：LIS 用「以 i 结尾」；背包用「容量 j」；编辑距离用「前 i 与前 j」。初始化与边界先写，避免越界。

加分点：能说出「状态定义错了，转移一定错；先小规模手算验证」。

**Q2：0-1 背包为什么容量要倒序？**

一句话结论：倒序保证 `dp[j-w[i]]` 还是上一轮物品的状态，当前物品最多用一次；正序会重复选当前物品。

展开：一维数组压缩了物品维度，正序会读到本轮已更新的值，相当于完全背包。

加分点：能说出「完全背包正序，0-1 背包倒序」。

**Q3：LIS 的 O(n log n) 解法在维护什么？**

一句话结论：维护「每个长度的递增子序列的最小结尾」，用二分替换，长度就是答案。

展开：`tails[l]` 是长度 l+1 的最小结尾；替换不改变已有长度，只让结尾更小，给后续更大机会。

加分点：能说出「tails 不是真正的 LIS，要还原序列需要前驱数组」。

**Q4：编辑距离的三个方向分别对应什么操作？**

一句话结论：左上替换、上删除、左插入；相等时直接继承左上。

展开：`dp[i][j]` 是 a 前 i 到 b 前 j 的最少操作；初始化第一行/列是插入/删除次数。

加分点：能说出「空间可以压缩到一维，但需要保存左上角旧值」。

**Q5：什么题不能用 DP？**

一句话结论：没有最优子结构、子问题不重叠、或有后效性时，DP 不成立。

展开：有后效性意味着当前状态无法概括历史，需要增加维度或换模型；NP-hard 问题不要指望多项式 DP。

加分点：能说出「先判断问题结构，再选方法，不要见题就 DP」。

## 小结

- **DP 的三个前提**：最优子结构、重叠子问题、无后效性。
- **四步法**：状态、转移、初始化、顺序；状态定义决定一切。
- **五类模型**：线性（LIS/子数组）、背包（0-1/完全/多重）、区间（回文/合并）、状态机（股票）、状压（集合）。
- **背包方向**：0-1 倒序、完全正序；求方案数用累加，求恰好装满用 `-INF`。
- **空间优化**：滚动数组要保证依赖顺序，必要时保存旧值。
- **先记忆化写对，再递推优化**；不要见题就套 DP。

# 数组、字符串与双指针：四个必须写到熟的模板

> 定位：数组和字符串是面试题的最大来源，也是工程里最常见的性能现场。这一篇只讲四个模板：双指针、滑动窗口、前缀和/差分、二分。每个模板都给适用条件、Java 代码、边界和常见变体，目标是「面试能写、线上能用」。

## 一、数组为什么快，链表为什么慢

| 维度 | 数组（ArrayList） | 链表（LinkedList） |
|---|---|---|
| 内存布局 | 连续 | 节点分散 |
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n) | O(1) |
| 缓存友好 | 高（预取命中） | 低（cache miss 多） |
| 额外空间 | 容量冗余 | 每节点两个指针 |

数组的「快」不只是 O(1) 下标，更是**CPU 缓存行预取**：连续内存一次加载 64 字节，后续访问大概率命中。链表遍历时每个节点都可能是一次 cache miss，所以同样是 O(n)，链表常常慢几倍。

工程结论：**绝大多数场景用 `ArrayList`**；只有已知位置频繁插入/删除、或需要队列语义时才考虑 `LinkedList`。`LinkedList` 的 `get(i)` 是 O(n)，在循环里用 `get(i)` 遍历会退化成 O(n²)，这是最常见的误用。

## 二、双指针：三种形态

### 2.1 对撞指针：有序数组两数之和

```java
int[] twoSumSorted(int[] a, int target) {
    int l = 0, r = a.length - 1;
    while (l < r) {
        int sum = a[l] + a[r];
        if (sum == target) return new int[]{l, r};
        if (sum < target) l++;
        else r--;
    }
    return new int[]{-1, -1};
}
```

为什么能线性：数组有序，`sum` 小说明左端太小，只能右移；`sum` 大说明右端太大，只能左移。每一步都排除一个元素，最多走 n 步。

适用：有序数组求和、去重、判断回文、合并两个有序序列、盛最多水的容器。

### 2.2 快慢指针：链表与环

```java
boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
```

快指针每次两步、慢指针一步，有环一定相遇；相遇后把一个指针放回头部，同速再走，第二次相遇点就是环入口。

适用：判环、找中点、找倒数第 k 个、删除重复节点。

### 2.3 归并双指针：合并两个有序序列

```java
int[] merge(int[] a, int[] b) {
    int i = 0, j = 0, k = 0;
    int[] c = new int[a.length + b.length];
    while (i < a.length && j < b.length) {
        c[k++] = a[i] <= b[j] ? a[i++] : b[j++]; // <= 保证稳定
    }
    while (i < a.length) c[k++] = a[i++];
    while (j < b.length) c[k++] = b[j++];
    return c;
}
```

这是归并排序、合并两个有序链表、外排序多路归并的公共骨架。

### 2.4 双指针的边界

- `while (l < r)` 还是 `l <= r`：看是否允许同一个元素用两次；
- 指针移动后要不要跳过重复元素（去重题）；
- 空数组、单元素、全相同，先想清楚再写；
- 链表题用哑节点 `dummy`，省掉头节点特判。

## 三、滑动窗口：连续子数组的通用解

### 3.1 固定窗口

```java
// 长度为 k 的子数组最大和
int maxSum(int[] a, int k) {
    int sum = 0, ans = Integer.MIN_VALUE;
    for (int i = 0; i < a.length; i++) {
        sum += a[i];
        if (i >= k) sum -= a[i - k];
        if (i >= k - 1) ans = Math.max(ans, sum);
    }
    return ans;
}
```

固定窗口的关键是「进一个、出一个」，不要每次重新求和。

### 3.2 可变窗口：最长无重复子串

```java
int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> last = new HashMap<>();
    int left = 0, ans = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (last.containsKey(c)) {
            left = Math.max(left, last.get(c) + 1);
        }
        last.put(c, right);
        ans = Math.max(ans, right - left + 1);
    }
    return ans;
}
```

窗口内始终维护「无重复」这个性质：右指针扩张，出现重复时左指针跳到重复字符的下一位。`Math.max` 不能省，因为 `left` 只能右移，不能回退。

### 3.3 可变窗口的通用判断

```java
int left = 0;
for (int right = 0; right < n; right++) {
    // 1. 把 a[right] 加入窗口
    while (/* 窗口不满足条件 */) {
        // 2. 把 a[left] 移出窗口
        left++;
    }
    // 3. 此时窗口满足条件，更新答案
}
```

适用：最长/最短满足条件的子数组、最小覆盖子串、限流计数、日志窗口统计。

### 3.4 滑动窗口的坑

- 窗口收缩条件写成 `if` 还是 `while`：要持续收缩到满足条件，通常用 `while`；
- 更新答案的时机：在窗口满足条件时更新，不要在扩张后立刻更新；
- 字符集固定时（如小写字母）用 `int[26]` 代替 `HashMap`，更快；
- 结果是最长还是最短，收缩逻辑相反。

## 四、前缀和与差分：把区间查询变成 O(1)

### 4.1 一维前缀和

```java
int[] prefix = new int[n + 1];
for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + a[i];
}
// 区间 [l, r] 的和
int sum = prefix[r + 1] - prefix[l];
```

`prefix[0] = 0` 是为了让 `l = 0` 时不用特判。前缀和适合「多次区间求和、数组不变」的场景；如果数组频繁修改，用树状数组/线段树。

### 4.2 二维前缀和

```java
int[][] p = new int[m + 1][n + 1];
for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++)
        p[i][j] = p[i-1][j] + p[i][j-1] - p[i-1][j-1] + a[i-1][j-1];

// 子矩阵 (r1,c1) 到 (r2,c2)
int sum = p[r2+1][c2+1] - p[r1][c2+1] - p[r2+1][c1] + p[r1][c1];
```

记忆方法：加左、加上、减重复；查询时减上、减左、加回重叠。

### 4.3 差分：区间加、单点查

```java
// 对 [l, r] 全部加 v
diff[l] += v;
diff[r + 1] -= v;
// 还原
for (int i = 1; i < n; i++) diff[i] += diff[i - 1];
```

差分是前缀和的逆运算：前缀和把「区间查询」变 O(1)，差分把「区间修改」变 O(1)。二维差分同理，用四个角标记。

### 4.4 前缀和的工程映射

- 监控指标按时间窗口聚合；
- 订单金额按区间对账；
- 图像处理中的积分图；
- 数据库里的累计快照表。

## 五、二分：统一用「下界」模板

### 5.1 第一个 ≥ target

```java
int lowerBound(int[] a, int target) {
    int l = 0, r = a.length;      // 注意 r = n
    while (l < r) {
        int m = l + (r - l) / 2;  // 防溢出
        if (a[m] < target) l = m + 1;
        else r = m;
    }
    return l;                     // 可能等于 n
}
```

三个边界：

1. `r = n` 而不是 `n - 1`，表示「可能插入到末尾」；
2. 循环条件 `l < r`，结束时 `l == r`；
3. 返回 `l`，它可能等于 `n`，调用方要处理。

### 5.2 第一个 > target（上界）

```java
int upperBound(int[] a, int target) {
    int l = 0, r = a.length;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] <= target) l = m + 1;
        else r = m;
    }
    return l;
}
```

「最后一个 ≤ target」= `upperBound(target) - 1`；「最后一个 < target」= `lowerBound(target) - 1`。

### 5.3 答案二分：不是数组也有二分

只要答案具有单调性，就能二分。例如「运载能力为 capacity 时，能否在 D 天内运完」：

```java
int shipWithinDays(int[] weights, int days) {
    int l = Arrays.stream(weights).max().getAsInt();
    int r = Arrays.stream(weights).sum();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (canFinish(weights, mid, days)) r = mid;
        else l = mid + 1;
    }
    return l;
}
```

适用：最小最大值、最短时间、最大最小化、切割数组、吃香蕉、平方根。判断函数 `canFinish` 必须是「capacity 越大越容易」的单调函数。

### 5.4 二分的坑

- `mid = (l + r) / 2` 在 `l + r` 超过 `int` 最大值时溢出；
- `r = n` 与 `r = n - 1` 的循环条件不同，混用会死循环或漏答案；
- 找不到时返回 `-1` 还是插入点，要按题意；
- 重复元素要明确「第一个」还是「任意一个」。

## 六、字符串：不可变带来的连锁反应

### 6.1 String 的基本操作

```java
String s = "abc";
char c = s.charAt(1);          // 'b'
int idx = s.indexOf("bc");     // 1
String sub = s.substring(0, 2); // "ab"
```

`substring` 在 Java 7+ 会复制底层数组（不再共享 `value`），所以大量截取会产生很多对象。

### 6.2 拼接：循环里别用 `+`

```java
StringBuilder sb = new StringBuilder();
for (String x : list) sb.append(x).append(',');
String result = sb.toString();
```

循环里 `s += x` 每次创建新 `String`，复杂度 O(n²)；`StringBuilder` 是 O(n)。JDK 9+ 的字符串拼接在编译期会优化成 `invokedynamic`，但循环里仍然建议显式 `StringBuilder`。

### 6.3 回文与字符统计

```java
boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
        while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
        if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r))) return false;
        l++; r--;
    }
    return true;
}
```

字符统计优先用 `int[26]` / `int[128]`，比 `HashMap` 快且省内存。

### 6.4 字符串匹配

- 朴素匹配 O(n×m)，适合短串；
- KMP 用 `next` 数组把匹配降到 O(n+m)，适合长文本；
- 工程里优先用现成库/正则，但要知道正则回溯可能 catastrophic backtracking。

## 七、二分答案实战：从「猜答案」到「判定」

二分答案的通用步骤：

1. 明确答案范围 `[lo, hi]`；
2. 写一个单调判定函数 `feasible(x)`；
3. 二分找最小可行/最大可行；
4. 注意 `lo` 的初值必须可行或从下界开始。

以「运输能力」为例：

```java
boolean canFinish(int[] w, int cap, int days) {
    int need = 1, cur = 0;
    for (int x : w) {
        if (x > cap) return false; // 单件都装不下
        if (cur + x > cap) {
            need++;
            cur = 0;
        }
        cur += x;
    }
    return need <= days;
}

int shipWithinDays(int[] w, int days) {
    int lo = Arrays.stream(w).max().getAsInt();
    int hi = Arrays.stream(w).sum();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canFinish(w, mid, days)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

常见变体：

- 最小化最大值：`hi = mid` 当可行；
- 最大化最小值：`lo = mid` 当可行，`mid = lo + (hi - lo + 1) / 2`；
- 浮点二分：固定迭代 100 次，避免精度死循环；
- 答案范围要包含「无解」边界，最后校验。

## 八、数组工程：环形缓冲与稀疏表

### 8.1 环形缓冲

固定容量、覆盖最旧数据的场景（日志缓冲、滑动窗口、音频缓冲）：

```java
class RingBuffer {
    private final int[] a;
    private int head, size;
    RingBuffer(int cap) { a = new int[cap]; }
    void add(int x) {
        a[(head + size) % a.length] = x;
        if (size == a.length) head = (head + 1) % a.length;
        else size++;
    }
    int get(int i) { return a[(head + i) % a.length]; }
}
```

复杂度 O(1)，但要注意「满/空」判定和并发写。

### 8.2 稀疏表（Sparse Table）

多次静态区间最值查询（RMQ），预处理 O(n log n)，查询 O(1)：

```java
int[][] st = new int[n][log2(n) + 1];
for (int i = 0; i < n; i++) st[i][0] = a[i];
for (int k = 1; (1 << k) <= n; k++)
    for (int i = 0; i + (1 << k) <= n; i++)
        st[i][k] = Math.min(st[i][k-1], st[i + (1 << (k-1))][k-1]);

int query(int l, int r) {
    int k = 31 - Integer.numberOfLeadingZeros(r - l + 1);
    return Math.min(st[l][k], st[r - (1 << k) + 1][k]);
}
```

只适合「数组不变、只查询」；有更新就用线段树/树状数组。

### 8.3 数组的边界测试表

| 用例 | 目的 |
|---|---|
| 空数组 | 是否越界/返回默认 |
| 单元素 | 循环是否执行 |
| 全相同 | 去重/窗口是否正确 |
| 递增/递减 | 二分边界 |
| 含 `Integer.MIN/MAX` | 溢出 |
| 目标不存在 | 返回 `-1` 还是插入点 |

写完代码先过这张表，比「我觉得对了」可靠。

## 面试高频问法

**Q1：为什么 ArrayList 随机访问快，LinkedList 慢？**

一句话结论：数组连续内存支持 O(1) 下标和缓存预取；链表要逐节点跳，O(n) 且 cache miss 多。

展开：`ArrayList.get(i)` 是一次地址计算；`LinkedList.get(i)` 从头或尾遍历。循环里用 `get(i)` 会退化成 O(n²)。

加分点：能说出「同样是 O(n)，数组遍历通常比链表快几倍」。

**Q2：滑动窗口什么时候用 while 收缩，什么时候用 if？**

一句话结论：窗口内可能有多个元素导致不满足条件时用 `while` 持续收缩；每次最多多一个非法元素时 `if` 也够，但 `while` 更稳。

展开：最长无重复子串、最小覆盖子串用 `while`；固定窗口只用进出各一个。

加分点：能说出「更新答案的时机在窗口满足条件之后」。

**Q3：二分查找最容易错的地方是什么？**

一句话结论：区间定义不统一。推荐固定用「左闭右开」`[l, r)`，循环 `l < r`，返回 `l`。

展开：`r = n`、`mid = l + (r-l)/2`、`l = m+1` 或 `r = m`；找第一个/最后一个用下界/上界变体。

加分点：能写出「答案二分」的模板，并说明判断函数必须单调。

**Q4：前缀和与差分分别解决什么问题？**

一句话结论：前缀和把区间查询变 O(1)，差分把区间修改变 O(1)；二者是互逆的。

展开：前缀和适合静态数组多次查询；差分适合多次区间加、最后一次性还原。

加分点：能说出二维前缀和的容斥公式。

**Q5：字符串循环拼接为什么慢？**

一句话结论：`String` 不可变，每次 `+` 都创建新对象并复制，循环 n 次是 O(n²)；用 `StringBuilder` 是 O(n)。

展开：JDK 9+ 编译期会用 `invokedynamic` 优化简单拼接，但循环里仍建议显式 `StringBuilder`。

加分点：能说出 `substring` 在 Java 7+ 会复制底层数组，不再共享。

## 小结

- **数组胜在连续内存与缓存局部性**，绝大多数场景优先 `ArrayList`；链表只在已知位置频繁插入/删除时有优势。
- **双指针三形态**：对撞、快慢、归并；链表题先用哑节点。
- **滑动窗口**：右扩、左缩、满足条件时更新答案；`while` 收缩更稳。
- **前缀和/差分**：区间查询与区间修改的 O(1) 工具，二者互逆。
- **二分固定「左闭右开 + 下界」模板**，答案有单调性也能二分。
- **字符串不可变**：循环拼接用 `StringBuilder`，字符统计用数组。

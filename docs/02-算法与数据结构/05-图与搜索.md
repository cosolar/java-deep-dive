# 图与搜索：BFS、DFS、拓扑与最短路

> 定位：图是「关系」的抽象：依赖、社交、路由、调度、推荐都能建模成图。面试考图的四种基本功——遍历、连通性、拓扑排序、最短路；工程上还要知道什么时候该用并查集、什么时候该上 Dijkstra。这一篇给模板、给边界、给选型。

## 一、图的表示：先选对存储

| 表示 | 空间 | 适用 | Java 实现 |
|---|---|---|---|
| 邻接矩阵 | O(V²) | 稠密图、频繁判断两点是否相连 | `boolean[][]` / `int[][]` |
| 邻接表 | O(V+E) | 稀疏图、遍历邻居 | `List<Integer>[]` |
| 边集 | O(E) | 只需要遍历边、Kruskal | `List<int[]>` |

绝大多数业务图是稀疏的，用邻接表。邻接矩阵在 V 超过几千时会吃掉大量内存。

```java
// 邻接表
List<Integer>[] g = new List[n];
for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
g[u].add(v);
g[v].add(u); // 无向图
```

## 二、BFS：无权图最短路

### 2.1 网格 BFS 模板

```java
int bfs(int[][] grid, int sr, int sc, int tr, int tc) {
    int m = grid.length, n = grid[0].length;
    boolean[][] vis = new boolean[m][n];
    Deque<int[]> q = new ArrayDeque<>();
    q.offer(new int[]{sr, sc});
    vis[sr][sc] = true;
    int step = 0;
    int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
    while (!q.isEmpty()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            int[] cur = q.poll();
            if (cur[0] == tr && cur[1] == tc) return step;
            for (int[] d : dirs) {
                int x = cur[0] + d[0], y = cur[1] + d[1];
                if (x < 0 || x >= m || y < 0 || y >= n) continue;
                if (grid[x][y] == 1 || vis[x][y]) continue;
                vis[x][y] = true;
                q.offer(new int[]{x, y});
            }
        }
        step++;
    }
    return -1;
}
```

要点：

- **入队时就标记 visited**，否则同一节点会被重复入队，复杂度爆炸；
- `size` 固定当前层，`step` 才是层数；
- 网格题的方向数组要按题意（四向/八向）。

### 2.2 为什么 BFS 能求最短路

BFS 按层扩展，第一次到达终点时走过的边数最少。前提是**边权相同（无权图）**；边权不同要用 Dijkstra。

### 2.3 多源 BFS

把所有源点一开始都入队，一次 BFS 求出每个点到最近源点的距离。典型题：腐烂的橘子、离建筑物最近的距离、多仓库配送范围。

## 三、DFS：连通性、回溯与拓扑

### 3.1 连通分量

```java
void dfs(int u, List<Integer>[] g, boolean[] vis) {
    vis[u] = true;
    for (int v : g[u]) {
        if (!vis[v]) dfs(v, g, vis);
    }
}

int components(List<Integer>[] g) {
    int n = g.length, cnt = 0;
    boolean[] vis = new boolean[n];
    for (int i = 0; i < n; i++) {
        if (!vis[i]) {
            cnt++;
            dfs(i, g, vis);
        }
    }
    return cnt;
}
```

### 3.2 回溯：DFS + 恢复现场

```java
void backtrack(int[] a, int start, List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path)); // 收集当前路径
    for (int i = start; i < a.length; i++) {
        path.add(a[i]);
        backtrack(a, i + 1, path, res);
        path.remove(path.size() - 1); // 恢复现场
    }
}
```

回溯的复杂度通常是指数级，必须靠剪枝控制；「组合/排列/子集/棋盘」都是这个骨架。

### 3.3 DFS 的坑

- 递归深度等于路径长度，长图会栈溢出，改显式栈；
- 有环图要标记「访问中/已访问」三态，否则会重复走；
- 回溯一定要恢复现场，否则下一次分支带着脏状态。

## 四、拓扑排序：依赖编排

### 4.1 Kahn 算法

```java
int[] topo(int n, int[][] edges) {
    int[] indeg = new int[n];
    List<Integer>[] g = new List[n];
    for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
    for (int[] e : edges) {
        g[e[0]].add(e[1]);
        indeg[e[1]]++;
    }
    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.offer(i);
    int[] order = new int[n];
    int idx = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[idx++] = u;
        for (int v : g[u]) {
            if (--indeg[v] == 0) q.offer(v);
        }
    }
    return idx == n ? order : new int[0]; // 空表示有环
}
```

用途：构建依赖、任务编排、课程表、包管理、工作流 DAG。

### 4.2 拓扑排序的变体

- 要求字典序最小：把队列换成小顶堆；
- 要求并行批次：按层出队，每一层是一批可并行的任务；
- 有环检测：输出节点数 < n 即有环；
- 反向拓扑：从汇点往回推，适合「影响传播」类问题。

## 五、最短路：先看边权

| 算法 | 适用 | 复杂度 | 限制 |
|---|---|---|---|
| BFS | 无权图 | O(V+E) | 边权相同 |
| Dijkstra | 非负权 | O((V+E) log V) | 不能有负权 |
| Bellman-Ford | 可有负权 | O(VE) | 可检测负环 |
| Floyd | 多源、小图 | O(V³) | V 通常 ≤ 500 |
| A* | 有启发函数 | 取决于启发式 | 启发函数需可采纳 |

### 5.1 Dijkstra

```java
long[] dijkstra(List<int[]>[] g, int src) {
    int n = g.length;
    long[] dist = new long[n];
    Arrays.fill(dist, Long.MAX_VALUE);
    dist[src] = 0;
    PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
    pq.offer(new long[]{0, src});
    while (!pq.isEmpty()) {
        long[] cur = pq.poll();
        long d = cur[0];
        int u = (int) cur[1];
        if (d > dist[u]) continue; // 旧记录，跳过
        for (int[] e : g[u]) {
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new long[]{dist[v], v});
            }
        }
    }
    return dist;
}
```

要点：

- 边权非负；有负权会破坏「已确定节点不再更新」的前提；
- Java 的 `PriorityQueue` 不支持 decrease-key，用「重复入堆 + 旧记录跳过」；
- 用 `long` 防距离溢出；
- 只求单源；多源可加超级源点或跑多次。

### 5.2 Bellman-Ford 与负环

对所有边松弛 V-1 轮；第 V 轮还能松弛，说明存在负环。复杂度 O(VE)，适合边数不大、可能有负权的场景。

### 5.3 Floyd

`dp[k][i][j]` 表示只经过前 k 个点时的最短路；三重循环，适合小图多源查询。注意循环顺序：k 必须最外层。

## 六、并查集：连通性近 O(1)

```java
class DSU {
    int[] p, sz;
    DSU(int n) {
        p = new int[n];
        sz = new int[n];
        for (int i = 0; i < n; i++) { p[i] = i; sz[i] = 1; }
    }
    int find(int x) {
        return p[x] == x ? x : (p[x] = find(p[x])); // 路径压缩
    }
    boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (sz[ra] < sz[rb]) { int t = ra; ra = rb; rb = t; }
        p[rb] = ra;
        sz[ra] += sz[rb];
        return true;
    }
}
```

用途：朋友圈、岛屿数量、冗余连接、Kruskal 最小生成树、动态连通性。

优化：路径压缩 + 按大小合并，均摊近 O(1)（反阿克曼函数）。

## 七、最小生成树：只要连通，不要最短路径

- **Kruskal**：边按权排序，依次加入，用并查集判环；O(E log E)，适合稀疏图。
- **Prim**：从一个点开始，每次加入连接已选集合的最小边；O(E log V)，适合稠密图。

别把「最小生成树」和「最短路」混了：MST 保证全图连通且总权最小，不保证任意两点间路径最短。

## 八、强连通分量：Tarjan 算法

有向图中，若两个点互相可达，它们属于同一个强连通分量（SCC）。Tarjan 用一次 DFS，借助 `dfn`（访问时间）和 `low`（能回溯到的最早时间）找 SCC。

```java
class Tarjan {
    int timer, sccCount;
    int[] dfn, low;
    boolean[] inStack;
    Deque<Integer> stack = new ArrayDeque<>();

    void dfs(int u, List<Integer>[] g) {
        dfn[u] = low[u] = ++timer;
        stack.push(u);
        inStack[u] = true;
        for (int v : g[u]) {
            if (dfn[v] == 0) {
                dfs(v, g);
                low[u] = Math.min(low[u], low[v]);
            } else if (inStack[v]) {
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
        if (low[u] == dfn[u]) {
            sccCount++;
            while (true) {
                int x = stack.pop();
                inStack[x] = false;
                // x 属于当前 SCC
                if (x == u) break;
            }
        }
    }
}
```

用途：循环依赖检测、强连通缩点、2-SAT、编译器优化。缩点后 DAG 上可做拓扑/DP。

## 九、DAG 上的 DP

DAG 没有环，按拓扑序可以放心做 DP。两类常见问题：

### 9.1 最长路径

```java
int[] dp = new int[n];
for (int u : topoOrder) {
    for (int v : g[u]) {
        dp[v] = Math.max(dp[v], dp[u] + weight(u, v));
    }
}
```

注意：DAG 最长路不能直接用 Dijkstra（负权/最长路不满足贪心），拓扑序 DP 是标准解。

### 9.2 路径计数

```java
long[] ways = new long[n];
ways[src] = 1;
for (int u : topoOrder) {
    for (int v : g[u]) ways[v] += ways[u];
}
```

若图有环，先 Tarjan 缩点，再在 DAG 上 DP；环内路径计数要单独处理。

### 9.3 工程映射

- 构建依赖的最长链决定最短工期；
- 任务编排的关键路径；
- 推荐/归因的路径传播；
- 编译器的依赖分析。

## 十、二分图匹配：匈牙利算法

二分图匹配求「最多有多少对可以配对」。匈牙利算法用 DFS 找增广路：

```java
boolean dfs(int u, List<Integer>[] g, int[] match, boolean[] vis) {
    for (int v : g[u]) {
        if (vis[v]) continue;
        vis[v] = true;
        if (match[v] == -1 || dfs(match[v], g, match, vis)) {
            match[v] = u;
            return true;
        }
    }
    return false;
}
```

对每个左部点清空 `vis` 后 DFS，成功则匹配数 +1。复杂度 O(VE)。

用途：任务分配、座位分配、广告主-流量匹配。大规模匹配用最大流/Dinic 或近似算法。

## 十一、图建模：把业务变成点与边

图题难在建模，不在模板。三个例子：

| 业务 | 点 | 边 | 算法 |
|---|---|---|---|
| 课程依赖 | 课程 | 先修关系 | 拓扑排序 |
| 社交关系 | 用户 | 关注/好友 | BFS/连通分量 |
| 路网导航 | 路口 | 道路 + 权重 | Dijkstra/A* |
| 服务调用 | 服务 | 调用依赖 | 环检测/拓扑 |
| 推荐传播 | 用户/物品 | 行为 | 图遍历/PageRank |

建模时先问：有向还是无向？带权还是无权？有没有环？需要单源还是多源？答案决定算法。

## 面试高频问法

**Q1：BFS 和 DFS 怎么选？**

一句话结论：无权最短路、层序、最小步数用 BFS；连通性、回溯、拓扑、深路径用 DFS。

展开：BFS 空间是宽度，DFS 空间是深度；网格题 BFS 要入队即判重；DFS 回溯要恢复现场。

加分点：提到「BFS 第一次到达终点的步数就是最短」。

**Q2：Dijkstra 为什么不能处理负权？**

一句话结论：Dijkstra 假设「已出堆的节点距离已确定」，负权边可能让后续路径更短，破坏这个前提。

展开：负权用 Bellman-Ford；负环用 Bellman-Ford 第 V 轮检测。

加分点：能说出「负权边不一定有负环，但 Dijkstra 仍不适用」。

**Q3：拓扑排序怎么检测环？**

一句话结论：Kahn 输出节点数小于 n，说明剩下的节点入度都不为 0，存在环。

展开：也可以 DFS 三态标记，遇到「访问中」节点即有环。

加分点：能说出「拓扑序不唯一，要求字典序时用小顶堆」。

**Q4：并查集为什么接近 O(1)？**

一句话结论：路径压缩把树压扁，按大小合并控制树高，均摊复杂度是反阿克曼函数，实际可视为常数。

展开：`find` 递归压缩路径；`union` 按大小/秩合并。

加分点：能说出「不优化时可能退化成链，find 变 O(n)」。

**Q5：什么时候用 Floyd，什么时候用 Dijkstra？**

一句话结论：多源、小图（V 几百）用 Floyd；单源、非负权、大图用 Dijkstra。

展开：Floyd O(V³) 但代码简单；Dijkstra O((V+E) log V) 更适合稀疏大图。

加分点：能说出「Floyd 的 k 必须放最外层，否则状态转移错误」。

## 小结

- **先选表示**：稀疏图用邻接表，稠密图/频繁判连通用邻接矩阵。
- **BFS 求无权最短路**，入队即判重，`size` 固定层；多源 BFS 一次求最近源。
- **DFS 管连通、回溯、拓扑**；有环用三态标记，回溯要恢复现场。
- **拓扑排序**用入度队列，输出不足 n 即有环；字典序用小顶堆。
- **最短路先看边权**：无权 BFS、非负 Dijkstra、负权 Bellman-Ford、多源小图 Floyd。
- **连通性用并查集**，路径压缩 + 按大小合并；MST 不等于最短路。
